# 文章字数与代码行数

所有文章在标题区显示构建时计算的正文字数；有代码块时另显示代码行数。页面只展示统计结果；统计规则记录在本文档中。

- 每个汉字计 1；其他语言的连续字母或数字按词计数，词内的点、下划线、连字符、单引号保留，例如 `README.md` 算 1。
- 包含正文标题、列表、表格、引用、链接文字与行内代码。
- 排除标点、文章元信息、链接目标地址、图片替代文字、MDX 导入、属性、表达式和嵌入组件实现。图示内文字不计入。
- 代码块统计非空行，包含注释；不计入正文字数。
- 在目录生成插件之前统计，避免自动目录重复计数。
- 本数值是中英混合内容的阅读量参考，不等于字符总数或阅读时长。

实现：`src/utils/remarkArticleStats.ts` 经 `astro.config.ts` 同时作用于 Markdown 与 MDX，通过渲染元数据交给 `ArticleStats.astro`。新增和修改文章后自动重新统计，无须维护 frontmatter 字段，也没有新增依赖。
