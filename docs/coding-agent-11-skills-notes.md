- 读者问题：Agent 怎样发现并按需取得任务相关的做法和资料，随后用已有工具完成任务？
- 当前场景：生成中文 Git 提交信息的 `commit-message` Skill，为本文编写的教学配置；管理模块代码来自 Ink 当前实现。仓库真实 `examples/skills/ledger/` 保留为参考链接。`/workspace/app` 为教学路径，示意图为上下文摘要，非实测记录。
- 范围：一篇讲发现、目录注入、读取正文/参考资料、用户显式调用及相关失败；不拆篇，不重讲工具执行、项目审批或扩展注册。

| 文章结论 | 源码与相关测试 | 条件与限制 |
| --- | --- | --- |
| 启动读取文件并保存元信息，正文不直接注入模型 | `src/core/skills.ts`: `loadSkills`、`scanSkillsDir`、`loadSkillFromFile`；`test/skills.test.ts` | 项目扫描受 trust gate 控制；同名先到者保留；显式路径优先 |
| 目录放入 system，正文后续通过 read 取得 | `src/runner.ts`: `RunnerImpl.assembleSystem`；`formatSkillsForPrompt` | 调用者要求 read 工具存在；不启用 format 函数的 bash 备用措辞；隐藏的技能不入目录 |
| 正文与参考资料按需进入 toolResult/history | `src/core/loop.ts`: `runAgentLoop`；`test/repl-skills.test.ts` progressive disclosure case | 测试的模型回复由 scriptedProvider 预设，不证明真实模型一定会选对技能 |
| `/skill:name` 展开为用户消息 | `expandSkillBlock`、`buildSkillCommands`；`src/repl/repl.ts`: commandContext、enqueuePrompt；`test/repl-skills.test.ts` | 交互命令需启用；重新读文件并去除 frontmatter；展示摘要不改变存储全文 |
| 文件丢失与命令期间运行中均不继续提交 | command catch、`allowedDuringRun: false`、dispatch tests | 运行中拒绝，而非自动等待；普通 read 失败作为工具结果返回 |
| Skill 提供做法，不增加工具/权限 | Skill 元信息结构、runner 组装、现有工具执行路径 | 隐藏目录不等于文件访问限制；说明不构成操作系统隔离 |
